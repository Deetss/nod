# Keys

| Key | Action |
|---|---|
| `j` / `k` | next / prev PR |
| `Enter` | open review |
| `]` / `[` | next / prev file |
| `v` | mark file viewed |
| `d` | interdiff toggle |
| `w` | wrap lines |
| `h` | hide viewed |
| `a` | approve |
| `r` | request changes |
| `c` | comment |
| `q` | reply (on a finding card) |
| `n` / `p` | next / prev diff line (in a diff) |
| `V` | start range, then `n` / `p` extend |
| `i` | comment on cursor line (in a diff) |
| `C` | comment on file |
| `Enter` | open or close thread (on a thread marker) |
| `x` | resolve or reopen thread (on a thread or finding card) |
| `Ctrl+Enter` | post reply (in a thread reply box) |
| `Ctrl+Enter` | submit review (in Finish review body) |
| `↑` / `↓` / `Enter` / `Esc` | move, choose or close the Finish review menu |
| `m` | auto-merge (in Issues, `m` is milestone) |
| `M` | admin merge |
| `y` | ready for review |
| `F` | fix failing checks |
| `b` | hand finding to the bot (on a finding card) |
| `H` | hand all findings to the bot |
| `S` | dispatch all findings to Orca (in Issues, `S` is start / stop work) |
| `O` | open on GitHub |
| `Y` | copy link |
| `s` | send message to Orca session, or dispatch a finding (in Issues, `s` is status) |
| `o` | open Orca session (in Issues, `o` is reopen) |
| `t` | details drawer (narrow) |
| `e` | expand description |
| `R` | refresh |
| `P` | pair phone |
| `,` | settings |
| `W` | closed window |
| `g o` / `g p` / `g i` / `g a` | org / PRs / Issues / Activity |
| `f` | filter |
| `/` | search |
| `?` | this help |
| `Esc` | back / close |

Every action also has a visible button.

## In the Issues view

The Issues view reuses the keys above where it can, and adds its own. The help sheet is what the app shows in `?`.

| Key | Action |
|---|---|
| `j` / `k` | next / prev issue |
| `Enter` | open issue |
| `Space` | select for bulk |
| `c` | comment |
| `l` | labels |
| `a` | assign |
| `A` | assign me / unassign me |
| `m` | milestone (in PRs, `m` is auto-merge) |
| `s` | status |
| `S` | start / stop work |
| `e` | edit title |
| `x` / `X` | close / not planned |
| `o` | reopen |
| `D` | dispatch with Orca |
| `L` | hand to Bot (or set up a bot while it is off) |
| `K` | check with Bot |
| `T` | ask bot to retry |
| `B` | split as the bot proposes |
| `g o` | open the issue’s Orca session |
| `g s` | send to the issue’s Orca session |
| `n` | new issue |
| `N` | new sub-issue |
| `E` | add existing issue as a sub-issue |
| `u` | go to the parent issue |
| `Alt+↑` / `↓` | move sub-issue |
| `Del` | remove sub-issue |
| `[` / `]` | prev / next comment |
| `i` | metadata sheet (narrow) |
| `.` | more comment actions |
| `O` | open on GitHub |
| `Y` | copy link |
| `R` | refresh |
| `P` | pair phone |
| `,` | settings |
| `W` | closed window |
| `g p` | PRs |
| `f` | filter |
| `/` | search |
| `?` | this help |
| `Esc` | back / close |

Sub-issue rows also have `↑` / `↓` to move between them, `Enter` to open, `Shift+F10` for the row menu and `E` for add existing. `L`, `T` and `B` carry the bot's name in the label.
